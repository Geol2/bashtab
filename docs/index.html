Git Bash를 [탭]으로.

평소 쓰던 Git Bash(mintty) 창을 그대로 탭 안에 담았습니다. 새 터미널을 배울 필요 없이, 창 열 개 대신 탭 열 개.

왜 bashtab?

터미널을 새로 만든 게 아니라, 원래 Git Bash에 탭만 달았습니다.

100%

진짜 mintty

탭마다 Git for Windows의 mintty가 그대로 돌아갑니다. 글꼴·색·~/.minttyrc·복사/붙여넣기 모두 평소 그대로.

~300KB

exe 하나로 끝

Rust + Win32로 만든 단일 실행 파일. 설치도, 런타임도, Electron도 없습니다.

38s → 2s

빠른 시작

보안 프로그램 때문에 Git Bash가 느린 PC에서도 바로 뜹니다. 프롬프트·git 브랜치 표시·자동완성은 그대로.

Ctrl+Tab

익숙한 탭 조작

브라우저처럼 새 탭, 닫기, 전환, Alt+숫자 이동. 휠클릭으로 닫고 더블클릭으로 엽니다.

얼마나 빨라지나요?

은행·보안 프로그램이 깔린 PC에서는 프로그램 하나 띄우는 데 1초씩 걸리기도 합니다. 기본 Git Bash는 시작할 때 그런 프로그램을 십여 개 실행합니다.

셸 시작 시간 (실측)

기본 Git Bash 로그인약 38초
bashtab약 1~2초

어떻게?

bashtab은 /etc/profile 대신, 외부 프로그램을 하나도 실행하지 않는 시작 스크립트를 씁니다. git 브랜치는 .git/HEAD를 bash 내장 기능만으로 읽고, 자동완성은 처음 Tab을 누를 때 불러옵니다. ~/.bashrc는 그대로 읽습니다.

단축키

bashtab 창이 활성화되어 있을 때만 동작합니다.

Ctrl + Shift + T새 탭 (또는 +, 탭 바 빈 곳 더블클릭)
Ctrl + Shift + W탭 닫기 (또는 휠클릭, ×)
Ctrl + Tab다음 탭
Ctrl + Shift + Tab이전 탭
Alt + 1~9N번째 탭 (9 = 마지막)
Ctrl + Shift + C / V복사 / 붙여넣기
